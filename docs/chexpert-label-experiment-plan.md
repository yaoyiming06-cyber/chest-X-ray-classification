# CheXpert 十标签处理实验方案

更新日期：2026-10-08。编写身份：代码手；执行方：Windows / RTX 4060 训练手。

本文是待执行的实验设计，不含已经训练得到的结果。标签定义以数据字典为准，比赛评估以比赛规则为准。

## 1. 实验问题与输出顺序

要回答的问题：同一模型、同一患者划分下，如何处理报告抽取产生的不确定标签，才能提高各病种的预测能力？类别不平衡与空白标签另设消融实验。

当前实验固定以下十个输出；比赛提交前必须按官方要求重新核对名称和顺序。

| 索引 | 标签 | 中文含义 |
| --- | --- | --- |
| 0 | Enlarged Cardiomediastinum | 心纵隔增大 |
| 1 | Pneumothorax | 气胸 |
| 2 | Consolidation | 肺实变 |
| 3 | Pneumonia | 肺炎 |
| 4 | Edema | 肺水肿 |
| 5 | Cardiomegaly | 心脏增大 |
| 6 | Atelectasis | 肺不张 |
| 7 | Lung Opacity | 肺部阴影 |
| 8 | Pleural Effusion | 胸腔积液 |
| 9 | No Finding | 无异常发现 |

这些是可以共存的观察标签，不是互斥疾病分类。原始表的全部 14 类仍须保留，用于标签审计和检查 No Finding；本轮模型只输出指定的 10 类。

## 2. 原始状态与证据边界

- `1`：报告标签阳性；`0`：报告标签阴性。
- `-1`：不确定；空白：未提及。读取 CSV 时必须保留二者的区别。
- 主实验把空白映射为 `0`，作为弱监督训练约定；这不表示医生明确排除了疾病。另做空白忽略实验。
- No Finding 使用原始字段做二分类。CheXpert 原论文中该类没有不确定样本；若实际统计出现 `-1`，先核查数据来源和处理过程。
- 不用九个病种的预测或标签反推 No Finding。其他未输出的观察结果也可能影响它；官方标签器的 Support Devices 不阻止 No Finding。原标签器未满足 No Finding 条件时该字段可为空白，该分支固定以原字段 1 为阳性、0/空白为阴性；这是一项报告标签任务约定，不能解释为影像专家真值。

CheXpert 原论文直接比较五类：Atelectasis、Cardiomegaly、Consolidation、Edema、Pleural Effusion。其最终逐类策略是 U-Ones、U-MultiClass、U-SelfTrained、U-Ones、U-MultiClass。这是该论文设置下的选择，不是全部十类、所有骨干和所有比赛数据的固定最优结论。

原论文指出部分策略差异不显著，不能仅凭单次小验证集排名宣称医学上某种策略更正确。固定软标签 `0.5` 是本项目补充对照，不等于原论文五种方法之一。

## 3. 固定实验条件

### 数据划分

1. 在 CheXpert 训练数据内按患者固定划分：训练 80%、调参验证 10%、锁定内部测试 10%。使用患者级多标签分层近似，确保少数类在各集合中有足够阳性；保存患者清单和划分哈希。
2. 同患者的所有 study 和图像归入同一集合。本轮先只用正面片；侧位片作为后续独立实验。
3. 调参验证用于选 epoch、策略、阈值和校准参数。锁定内部测试不用于这些选择，最终候选确定后一次性评估。
4. 训练 CSV 留出的标签仍是报告抽取弱标签，10 类结果属于弱标签一致性评估，不能当成专家确诊性能。
5. 官方专家标注验证数据单独用于五类最终参考评估。先核查实际标签文件、标注来源和可用性；不能仅因某个 CSV 有 14 列就声称它提供十类可靠专家真值。
6. 如果有比赛提供的可靠验证标签，增加比赛域评估；不确定策略只作用于训练标签，评估真值不随实验组映射。

### 模型与训练

- 按现有选型使用 EVA-X-S 通用预训练骨干，重新初始化任务头。核查预训练来源和比赛许可，记录留出患者是否曾进入预训练；若无法排除，披露这一限制。
- 不用已在 CheXpert 上监督微调的权重初始化标签策略主对比，否则先前标签策略和留出数据可能污染比较。
- 全部对比使用同一输入 224 x 224、同一预处理和增强、同一优化器、学习率、训练步数上限及选 epoch 规则。
- RTX 4060：AMP，物理 batch 从 8 起步，梯度累积到有效 batch 32；以实测显存为准。num_workers 从 0 起步。
- 先用小样本跑 1 个 epoch 排查路径、掩码和损失，再统一确定正式训练预算。正式筛选不因某组暂时低分就随意缩短训练。
- 单种子筛选用 `42`；复验用 `42/2026/3407`。同一随机种子尽量共享初始化和数据顺序，保存软件版本与 Git commit。
- 若 EVA-X 环境未跑通，可在 DenseNet121 上跑独立完整筛选，但不能把两种骨干的结果混在同一策略排名中。最终应在选定主模型上重新比较候选策略。

## 4. 第一轮：六组统一策略

九个病变分支统一应用每组策略，No Finding 始终做原字段二分类；空白统一映射为 `0`。这一轮所有类别权重设为 1，避免 pos_weight 与标签策略同时变化。

| 编号 | 策略 | 训练时如何处理 -1 | 头与损失 | 目的 |
| --- | --- | --- | --- | --- |
| E0 | U-Ignore | 该图像的该类别不参与损失 | 10 个二分类 logits，masked BCE | 稳健基准、教师模型 |
| E1 | U-Zeros | 映射为 0 | 10 个 logits，BCE | 检查把不确定当阴性的影响 |
| E2 | U-Ones | 映射为 1 | 10 个 logits，BCE | 检查把不确定当阳性的影响 |
| E3 | U-Soft-0.5 | 目标设为固定 0.5 | 10 个 logits，soft-target BCE | 中性软目标补充对照 |
| E4 | U-MultiClass | 保留为第三种训练状态 | 九个独立三分类头加一个二分类头 | 显式学习不确定状态 |
| E5 | U-SelfTrained | 用 E0 教师概率替换 | 新学生模型，soft-target BCE | 让图像信息决定不确定样本目标 |

### 损失实现要求

- BCE 直接接收 logits，不先 sigmoid。E0 只屏蔽该标签，保留图像对其他确定标签的训练作用。
- 采用逐类有效样本均值后对有效类别平均：`L_c = sum(mask_c * loss_c) / sum(mask_c)`；批内无有效目标的类别跳过。不要用包含被忽略项的固定分母稀释梯度。
- E4 每个病变头分别对阴性、阳性、不确定做三分类 CE；No Finding 使用 BCE。共有 `9 * 3 + 1 = 28` 个 logits，分支损失分别归一化再平均。
- E4 二分类推理概率为 `p_positive / (p_positive + p_negative)`，稳定实现可用 `sigmoid(z_positive - z_negative)`；另保存 `p_uncertain` 用于分析。只在每个分支内部 softmax，十个标签之间不做 softmax。
- E4 具有额外输出参数和不同损失形式，记录这一结构差异，不把比较说成完全相同输出结构。
- E5 教师只在训练患者数据上训练，用调参验证选定 checkpoint，然后切换 eval 模式，为训练集中的 `-1` 缓存概率。确定的 0/1 和空白处理不变，学生从相同通用预训练权重重新开始。
- 教师在自身训练集上生成软目标符合原始自训练基线；它不是独立真值。交叉拟合教师、置信度筛选和迭代伪标签放在后续实验，不在本组悄悄加入。

## 5. 第二轮：十分支混合候选 E6

先画每类在 E0-E5 中的 AUROC/AUPRC 表，再在调参验证上提出一份逐类混合配置。九个病种都有第一轮全部策略对照；下表只给优先关注方向，不能替代测量。

| 标签 | 优先关注候选 | 依据与待验证之处 |
| --- | --- | --- |
| Enlarged Cardiomediastinum | Ignore / MultiClass / Soft | MultiClass 是结构相近病种的迁移假设，没有原论文该类最优证明 |
| Pneumothorax | Ignore / Zeros / SelfTrained | 不确定比例与本地样本质量需统计，不能预设 SelfTrained 必胜 |
| Consolidation | Ignore / SelfTrained / Soft | 原论文最终选 SelfTrained；须复验少数类召回和精度 |
| Pneumonia | Ignore / Soft / SelfTrained | 不确定报告不等于影像确诊，伪标签可能放大教师错误 |
| Edema | Ignore / Ones / Soft | 原论文最终选 Ones；检查假阳性增加情况 |
| Cardiomegaly | Ignore / MultiClass / Soft | 原论文最终选 MultiClass |
| Atelectasis | Ignore / Ones / SelfTrained | 原论文最终选 Ones，且与 Zeros 的差异有较强证据 |
| Lung Opacity | Ignore / Ones / Soft | 较宽泛的影像观察，需评估与其他标签共现及标注噪声 |
| Pleural Effusion | Ignore / MultiClass / Ones | 原论文最终选 MultiClass；候选间差异可能很小 |
| No Finding | 原字段二分类 | 无不确定处理对比，另查标签冲突和错误案例 |

选择规则：先按预先指定的主指标排序；若候选差异小于预先登记的最小有意义差异，暂取实现较简单、稳定性较好的策略，交由多种子复验判断，不逐类硬凑单次最高分。

E6 从头训练共享骨干和混合头：二分类分支用 BCE，MultiClass 分支用三分类 CE，SelfTrained 分支用缓存软目标；逐类归一化后平均。混合训练会改变共享特征，所以拼出配置后必须实际重训和评估。拼接多个模型的逐类输出属于另一个集成实验。

优先只做一组 E6；如预算充足，再增加一组仅按原论文五类配置、其他四病种 Ignore 的文献对照。逐类全组合的 `6^9` 搜索不执行。

## 6. 第三轮：稳定性、类别权重与空白标签

### 稳定性复验

- E0-E6 中选两套候选配置，在三个种子上比较；已跑过的 seed 42 可以复用。
- 报告逐类和总体指标的均值、标准差。根据调参验证三种子结果确定最终方案，之后冻结所有设置。
- 在锁定测试上按患者做配对 bootstrap（建议 1000 次），报告性能差的 95% 区间。种子波动与患者抽样区间分别报告，不能合并当成一种误差。
- 10 类逐类比较有多重选择风险；小差异或少阳性类别不宣称确定获胜。正式显著性检验需要预先约定并做多重比较校正。

### pos_weight 独立消融

对两套候选配置分别比较权重关闭/开启，形成 `2 套标签配置 x 2 套权重设置`。这是第一轮之后的损失权重研究。

- 权重只从训练患者统计；BCE 在该实验实际参与损失的标签上计算 `w_c = N_negative,c / N_positive,c`。
- Ignore 不把被屏蔽的 `-1` 计入正负数；Ones/Zeros 使用映射后的计数。
- Soft/SelfTrained 使用有效目标质量：`N_positive = sum(y)`、`N_negative = sum(1-y)`，并单独记录软目标来源。这是加权约定，不是真实患病率。
- 预先固定保护规则，例如 `w_c = min(20, max(1, ratio))`，并保存原始比值和最终值；无有效阳性时先报错检查标签，而非依靠任意大权重继续训练。
- 如候选包含 MultiClass，CE 无法直接使用 BCE 的 pos_weight。其加权实验采用分支 CE 权重 `[1, w_known, 1]`，其中 `w_known` 仅由负/正状态计数计算并使用同一保护规则；须标明这是独立 CE 加权扩展。
- 比较 AUPRC、AUROC、召回、精度及校准，而不是只看训练 loss 是否下降。加权会改变概率校准，最终阈值和校准参数须重新在调参验证上拟合。

### 空白标签敏感性

对最终候选的九个病变分支比较 B0（空白映射 0）与 B1（空白忽略）。保留 -1 策略、训练预算等其他设置；如使用权重，两组各自按有效标签重新计算并记录。

B1 是训练目标变化，不是评估标签变化。评估集合与掩码保持固定；否则“忽略困难样本”本身就会虚增指标。内部十类弱标签评估主报告使用固定的空白映射 0 视图，各组均排除 -1 真值。九个病变分支补充报告仅明确 0/1 子集的指标与覆盖率；这个子集存在选择偏差，只用作敏感性分析。

No Finding 在 B0/B1 中都固定以原字段 1 为阳性、0/空白为阴性，不参与空白忽略消融。否则原标签器产生的该列可能只剩阳性，失去二分类监督。若数据版本已把未提及预先填成 0，九个病变分支也无法再做可靠的 B1，须记录此限制。

## 7. 指标与冻结规则

- 比赛指标未知时，实验主指标预先设为 10 类 macro AUROC；必报 macro AUPRC 和逐类指标。稀有类 Pneumonia、Consolidation 的 AUPRC 与召回作为重点观察项，不能训练后临时换主指标来宣布胜出。
- 比赛明确指标后，在正式筛选前登记并使用比赛指标；F1 比赛需在调参验证确定逐类阈值，AUROC 比赛保留连续概率。
- 五类专家参考 mAUROC 与十类弱标签 mAUROC 分开命名、分开表格，不互相替代。
- 二分类评估某类别只有一个真值类别时 AUROC 记为 NA，列出阳性/阴性数量与有效宏平均类别数；AUPRC 也须标明无阳性等不可解释情形。跨组必须使用同一有效类别集合。
- F1、Precision、Recall 的阈值都由调参验证确定；可另报预先指定特异度（例如 90%）下的召回，但这只是实验工作点，不等于临床部署标准。
- 保存概率以检查 Brier score、可靠性图以及疑似标签噪声。病例错误分析优先检查漏检病变、装置/文字捷径和 No Finding 冲突。
- 最终比赛推理时输出十类阳性概率或阈值化结果，格式完全遵守提交要求；不把不确定状态作为额外提交列，也不强制九类疾病互斥。

## 8. RTX 4060 执行顺序与预算

1. 数据统计和 smoke test：输出每类 1/0/-1/空白数量，以及各划分阳性患者数。
2. 跑 E0，再缓存教师对训练不确定项的概率。
3. 跑 E1、E2、E3、E4、E5；单种子六次训练，E5 复用 E0 教师，无需再训同一教师。
4. 看逐类结果，提出并跑 E6；累计七次训练。
5. 两套候选补跑两个种子，追加四次，累计十一趟主要模型训练。若候选使用 SelfTrained，每个新种子还需对应的 E0 教师；可共享同种子的教师缓存。E0 未包含在两套候选时额外增加两次教师训练，须另记训练与推理预算。
6. 预算允许时先用 seed 42 做两套候选的权重开启组，追加两次；如果排名改变，再补种子。预算再允许才做 B1。
7. 锁定方案后评估内部测试与可用专家参考集，生成冻结配置和错误分析。

若资源有限，先完成 E0/E1/E2 三组；没有这些基准时不直接投入复杂伪标签。总耗时需从本机完整 epoch 和教师推理实测推算，不能只凭 RTX 4060 型号承诺小时数。

## 9. 训练手结果回传

每轮至少交付以下小文件（这里是未来训练输出约定，当前尚未生成）：

- `experiment_summary.csv`：实验号、数据/划分哈希、Git commit、模型与初始化、种子、标签策略、空白策略、类别权重、训练预算、选中 epoch、主指标、耗时和峰值显存。
- `per_label_metrics.csv`：实验号、种子、评估集合与真值来源、标签、有效覆盖率、阳性/阴性数、AUROC、AUPRC、F1、Precision、Recall、阈值。
- `label_statistics.csv`：逐类原始四状态计数、处理后目标计数及最终类别权重。
- `selected_label_policy.json`：逐标签策略、教师 checkpoint 标识、阈值/校准来源、输出顺序。
- 本地保存 checkpoint、教师软标签缓存与逐图概率；患者相关明细及大文件不提交 Git。

交接摘要须注明：身份为训练手，接收方为代码手；包括完成的实验号、失败信息和下一步建议。方案实施仍需训练入口、数据读取、混合损失及评估代码；当前文档不代表这些入口已经存在。
